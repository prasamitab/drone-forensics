# Keyword Search Output

## Purpose

Autopsy Keyword Search was used to locate strings associated with the
synthetic artifacts in the disk image.

## Search terms

```text
malware
backdoor
password
```

## Recorded associations

| Keyword | Associated file |
|---|---|
| `malware` | `malware_log.txt` |
| `backdoor` | `backdoor_info.txt` |
| `password` | `stolen_data.txt` |

## Interpretation

The keyword searches demonstrated how relevant strings can be located
within recovered files. A keyword hit alone does not prove malware
execution, persistence, credential theft, or data exfiltration.

All files used in this experiment were synthetic test artifacts.
